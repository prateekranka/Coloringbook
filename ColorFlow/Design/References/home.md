# Home Tab — Design References

## Current State
- Section headers ("My Recent Work", "Inspiration", "Suggested For You") + horizontal scroll rows
- Centered hero card with "Browse Templates" and "From Photo" buttons
- Empty state is plain text ("No projects yet — start coloring!")
- Functional but lacks visual punch

## References

### 1. Procreate — Hero Artwork Dominance
- **URL**: https://procreate.com/en/procreate
- **What to borrow**: Hero artwork fills the viewport. The app's value is shown immediately through stunning artwork, not through UI chrome. ColorFlow's hero should show a beautiful colored template, not a centered CTA box.
- **Apply to**: Featured template card at top of Home

### 2. The Atlantic — Featured Card Pattern
- **URL**: https://theatlantic.com (mobile)
- **What to borrow**: A single large featured story card dominates the fold. Secondary content (recent, suggested) sits below. The hierarchy is clear: one hero, then rows.
- **Apply to**: Replace the centered "Start Coloring" box with a full-width featured template card with gradient overlay

### 3. Pocket Casts — Dark Theme Section Hierarchy
- **URL**: Pocket Casts mobile app (dark theme)
- **What to borrow**: Clean section headers with subtle dividers, consistent card sizing, polished empty states with illustrations. The dark background makes content pop.
- **Apply to**: Section header styling, empty state treatment

### 4. PicsArt — Welcome Modal + Home Feed
- **URL**: PicsArt mobile app
- **What to borrow**: "Start creating" modal on home feed for returning users. The home feed shows inspiring content that motivates action.
- **Apply to**: Empty "My Recent Work" section — show an inspiring CTA instead of plain text

### 5. The Atlantic / CapCut — Section Cards with Visual Weight
- **What to borrow**: Cards have rounded corners, subtle shadows, and images that fill the card face. No white rectangles — the image IS the card.
- **Apply to**: Inspiration and Suggested template cards

## Proposed Changes Summary
1. **Hero**: Full-width featured template with gradient overlay + "Start Coloring" CTA overlay
2. **Recent Work**: Empty state gets an illustration + "Start your first project" CTA
3. **Inspiration/Suggested**: Cards become image-first (no white border), add subtle scale on hover
4. **Overall**: Reduce vertical spacing, make the hero section take more visual weight
