# Library Tab — Design References

## Current State
- Category pill bar (underline style) at top
- Search bar in navigation drawer
- Adaptive grid of white template cards with difficulty pills
- Template thumbnails render inside white rounded rectangles

## References

### 1. CapCut — Template Grid with Filter Chips
- **URL**: CapCut mobile app (Templates tab)
- **What to borrow**: Filter chips (Following, For You, Premium) above a scrollable grid. Cards show view counts and engagement signals. The grid feels alive, not static.
- **Apply to**: Add "Popular" / "New" / "Easy Start" filter chips above the template grid

### 2. Canva — Search + Category Chips
- **URL**: https://canva.com (mobile app)
- **What to borrow**: Search bar is prominent at the top. Category chips are horizontally scrollable with a "See all" option. Template cards show the design name and a "Use" button.
- **Apply to**: Make search more prominent, add "See all" links per category

### 3. Adobe Express — Category Tabs + Template Grid
- **URL**: Adobe Express mobile app (Templates section)
- **What to borrow**: Category tabs (Templates, Photos, Videos, Design assets) with a clean grid below. Each card has a subtle favorite/heart icon. Filter and notification icons in the nav bar.
- **Apply to**: Add favorite/heart icon on template cards, improve category bar styling

### 4. Replit Gallery — Engagement Metrics on Cards
- **URL**: https://replit.com/gallery
- **What to borrow**: Grid cards show thumbnails, titles, authors, tags, and view/like counts. This social proof helps users pick templates.
- **Apply to**: Add subtle engagement signals (popularity badge, "trending" label)

### 5. Chameleon — Colorful Template Grid with Sidebar
- **URL**: https://www.chameleon.io/templates
- **What to borrow**: Colorful template cards that feel like real previews, not placeholder thumbnails. The grid has variety in card sizes (some larger for featured items).
- **Apply to**: Make template cards feel more like real previews

## Proposed Changes Summary
1. **Category bar**: Keep underline style, add "Popular" / "New" filter chips
2. **Template cards**: Image-first (no white border), add favorite icon, show category icon when no thumbnail
3. **Grid**: Consider a featured row at top (larger cards), standard grid below
4. **Search**: More prominent, with recent searches and suggestions
5. **Empty state**: Better illustration when no templates match filters
